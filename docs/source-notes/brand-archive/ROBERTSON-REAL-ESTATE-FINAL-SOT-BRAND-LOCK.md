## Cleanup Rule

Keep:
- Hybrid SOT palette
- Geist Sans + Inter
- Option A logo lockup
- Final SOT hero
- Joel portraits
- R mark / seal / favicon system

Archive:
- Montserrat recommendation
- all-clay-only board
- old gold-only board
- earlier hero variants
- previous brand-board drafts
- previous warm-token palette notes

Exclude from brand kit:
- generic stock people as identity
- content house photos as brand drivers
- placeholder marks
- stretched logo crops
- burned-in hero text/buttons
- vendor-template styling

## Production Use

Place final approved assets in a clean brand folder and keep content imagery separate from identity imagery.
