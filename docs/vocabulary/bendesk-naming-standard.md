# BenDESK Naming Standard

## Ben functional names

Pattern:

`Ben{CODE}`

Rules:

- `CODE` MUST be exactly 3 or 4 uppercase characters.
- The code MUST identify a semantic function.
- `BenOA` is the sole permitted 2-character exception.
- New 2-character Ben names are prohibited.

Examples:

- BenDESK
- BenROLE
- BenZONE
- BenNOTE
- BenCODE
- BenSOT
- BenLOG
- BenTOK
- BenGEO
- BenOA

## Layers

- BenDESK — template/template system
- BenSOT — canonical authority
- BenNOTE — notes and Obsidian knowledge interface
- BenCODE — code and implementation
- BenOA — Ouroboro Archives
